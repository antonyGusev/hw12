# IoT Smart Climate Controller


**IoT Smart Climate Controller** — це IoT-пристрій на базі ESP32 для автоматичного підтримання заданої температури та вологості в приміщенні.

Пристрій отримує дані з датчика температури та вологості SHT31 і, залежно від поточних значень та заданих порогів, керує:

- кондиціонером у режимах `HEAT`, `COOL`, `DRY`, `OFF`;
- системою зволоження;
- автоматичним наповненням резервуара для води.

Система підтримує режими `AUTO` та `MANUAL`, віддалене керування і моніторинг через MQTT, збереження конфігурації в енергонезалежній пам’яті та обробку аварійних станів.

Проєкт також використовується як тестовий об’єкт для побудови HIL/E2E automation framework, який дозволяє емулювати сенсори, перевіряти керуючі сигнали та автоматизувати функціональні й нефункціональні перевірки пристрою.
